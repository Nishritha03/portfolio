TC-01 Method

Three things I actually believe about testing

I care less about how many test cases I ran and more about whether the release actually holds up in production.

01

Reproduce before you file

A bug I can't reproduce reliably isn't fixed yet — it's just hiding. I write the steps down before I even file it.

02

Automate the third repeat

If I've run the same manual check three times, it becomes a Playwright script the fourth time — not a note-to-self.

03

Trace it to the receipt

"It's slow" isn't a bug report. I follow it down to the query, the lock, the endpoint — then hand over the receipts.
